# Superpowers Design Phase

This workflow uses the `brainstorming` skill (as `superpowers-brainstorming`) to help design your new feature.

Please ensure you have run the Antigravity installation scripts so the skill is globally available.

**Action**: Ask the agent to run the `superpowers-brainstorming` skill for the feature you wish to design.
